# 常见问题排查

## 1. RMSECV 远大于 RMSEC → 过拟合
**原因**：成分数过多，模型拟合了噪声。
**处理**：
- 减少 PLS 成分数（用 Haaland-Thomas 保守准则）
- 增加样本量
- 加强预处理降噪（SG平滑）
- 检查异常样本

## 2. RMSEP 远大于 RMSECV → 验证集不具代表性
**原因**：验证/测试集的样本分布与训练集差异大。
**处理**：
- 检查样本划分（Kennard-Stone 划分更均匀）
- 增加样本多样性
- 检查是否不同批次/仪器

## 3. 模型随时间退化 → 漂移
**原因**：仪器老化、光源衰减、环境变化。
**处理**：
- 定期漂移检测（马氏距离）
- 重新校准
- 用传递标准品校正

## 4. R² 很低（<0.6）→ 数据质量问题
**排查**：
- 异常样本（PCA-T² 检测）
- 参考值测量误差
- 光谱信噪比低
- 样本代表性不足
- 目标属性与光谱无相关

## 5. bias 很大 → 系统误差
**原因**：训练/测试集参考值标定不一致。
**处理**：
- 检查参考方法一致性
- 应用偏差校正（预测值 - bias）
- 重新校准

## 6. 预处理后出现 NaN/Inf
**原因**：除零（std=0、零范数行）。
**处理**：
- nir_core 已有保护（返回0），但检查输入是否有全零光谱
- 用 validate_spectra 检查

## 7. PLS 成分数选不准
**处理**：
- 用 Haaland-Thomas 保守准则
- 检查 RMSECV 曲线是否平滑
- 增加CV折数

## 8. 不同预处理结果差异大
**正常**：预处理对结果影响大。
**处理**：
- 用嵌套CV客观选择
- 并行比较多种预处理
- 选择最稳健的（非最乐观的）

## 9. 波长选择后性能下降
**原因**：波长选择泄露（在CV外做）或选了噪声波长。
**处理**：
- 波长选择必须在CV内部
- 减少选择波长数
- 用 CARS/SPA 后在测试集独立验证

## 10. SVR 比 PLS 差
**常见**：NIR 多为线性关系，SVR 易过拟合。
**处理**：
- 优先 PLS
- SVR 调参（C, gamma 网格搜索）
- 确认非线性确实存在
