# 预处理方法选择指南

## 决策树

```
样本类型?
├─ 固体粉末/颗粒 → SNV (逐条独立，无需参考)
├─ 液体/澄清 → MSC 或 SNV
├─ 浆料/悬浊液 → SNV + 基线校正
└─ 未知 → SNV 起步
```

## 方法详解

### 散射校正
| 方法 | 优点 | 缺点 | 适用 |
|------|------|------|------|
| SNV | 逐条独立，无需参考谱 | 不能校正波长相关散射 | 颗粒size变化大 |
| MSC | 校正乘性散射 | 需参考谱（均值） | 有稳定基线时 |

### 平滑与导数
| 方法 | 作用 | 注意 |
|------|------|------|
| SG平滑 | 降噪 | window过大失真，过小无效 |
| 1阶导数 | 消除常数基线，分离重叠峰 | 放大噪声，需先平滑 |
| 2阶导数 | 消除线性基线 | 噪声更大 |

### 基线校正
| 方法 | 适用 |
|------|------|
| airPLS | 复杂基线漂移，自适应 |
| asLS | 平缓基线 |
| detrend | 线性/二次趋势 |

### 缩放
| 方法 | 作用 |
|------|------|
| mean_center | 去均值，PLS常用 |
| autoscale | 均值+单位方差，各波长等权 |
| normalize | 逐行归一化 |

## 流水线排序规则
散射校正 → 平滑 → 导数 → 基线校正 → 缩放。

## 何时用导数 vs 基线校正
- 导数：放大噪声，但能分离重叠峰
- 基线校正：适合平滑漂移，不放大噪声
- 噪声大时优先基线校正；需分离峰时用导数（先平滑）

## SNV vs MSC
- SNV：逐条独立，无参考，最稳健
- MSC：需参考谱（均值），train/val须用同一参考（防泄露）
