# 化学计量学硬规则（必读）

> 以下规则是近红外多元校正的铁律，任何分析都必须遵守。

## 1. 三集分离（防数据泄露）

- **必须**将数据分离为训练集、验证集、测试集，三者无样本重叠。
- **训练集**：模型拟合 + 内部交叉验证选参。
- **验证集**：预处理流水线选择（嵌套CV外循环评估）。
- **测试集**：最终独立评估，**绝不参与任何参数选择**。

## 2. 交叉验证

- **必须**用交叉验证选择潜变量数（PLS成分数）。
- 交叉验证只在**训练集**上进行，验证集和测试集不参与。
- 嵌套CV：外循环评估预处理，内循环选成分数，验证集不进内循环。

## 3. 预处理防泄露

- 需要跨样本统计的预处理方法（均值中心化、自缩放、MSC）**必须**在训练集上计算统计量，再应用到验证/测试集。
- 不能用验证/测试集自身的统计量预处理（否则信息泄露）。
- nir_core 的 PreprocessingPipeline.fit/transform 已实现此机制。

## 4. 波长选择

- 波长选择（CARS/SPA）**必须**在交叉验证的内部循环中进行，或仅在训练集上做。
- 不能用全量数据选波长再交叉验证（泄露）。

## 5. 预处理顺序

标准顺序：散射校正 → 平滑 → 导数 → 基线校正 → 缩放。
- 散射校正（SNV/MSC）去除物理散射
- 平滑（SG）降噪
- 导数消除重叠峰/基线漂移
- 基线校正（airPLS/asLS）去趋势
- 缩放（均值中心化/自缩放）标准化

## 6. 评估指标

- **RMSEC**（训练集RMSE）：反映拟合程度，过低警示过拟合。
- **RMSECV**（交叉验证RMSE）：反映模型泛化能力，选成分数的依据。
- **RMSEP**（测试集RMSE）：最终评估，最关键。
- **R²**：决定系数，越接近1越好。
- **RPD** = std(y)/RMSEP：>3 优秀，2-3 良好，1.5-2 一般，<1.5 差。
- **bias**：系统偏差，应接近0。
- **slope**：预测对参考的回归斜率，应接近1。

## 7. 过拟合识别

- RMSEC << RMSECV：过拟合，减少成分数。
- RMSECV << RMSEP：验证集不具代表性，或过拟合验证。
- R²_train 高但 R²_test 低：过拟合。

## 8. 样本量要求

- 每个成分至少 10-20 个样本（经验法则）。
- PLS 成分数不超过 min(n_samples/10, n_wavelengths)。
- 小样本（<100）时质量阈值应放宽。
