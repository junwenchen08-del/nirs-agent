# 开始分析

1. 登录 ChemAgent；首次启用时由管理员完成账户初始化。
2. 在数据集库上传文件，检查目标列、光谱方向、波长轴和样本角色。需要时在解析设置中修正映射。
3. 保存解析版本，将数据集挂载到新会话，说明分析目标、目标变量和约束，再手动发送。
4. 如果智能体请求确认，请在同一会话回复。等待问题时不会自动继续执行。
5. 从建模过程查看实际轮次、指标范围、诊断图和最终报告。模型入库遵循人工审批。
