# 工作台操作

## 数据集库

新对话提供“上传数据”“选择数据集”和“使用已有模型”三个入口。选择资源不会自动开始分析，填写任务并手动发送后才会执行。

数据集工作台按“样本与光谱”“数据概览”“解析设置”组织。波段范围在光谱旁调整；勾选样本后可批量设置用途。修改后先保存，再在新对话中使用；未保存修改会保留离开确认。

## 建模过程

全过程画布从数据准备展示到建模、最终评价、交付和保存。点击任意节点，右侧在“概览”“参数”“诊断图”“LLM 建议”中查看对应记录，左右面板保持等高。轮次时间线与原有方案关系图仍可切换，选择与详情分区在刷新后恢复。

诊断图按预测诊断、光谱对照、参数搜索和轮次比较分组。散点图和残差图共享样本选择及缩放，每张过程图均可放大。最终测试图只在评价完成后读取；历史未记录的图表会明确说明，不会因浏览而补算。

## 模型库与方法库

模型详情按“预测效果”“训练数据”“处理方法”组织。预测效果可切换已有评价范围，来源预览使用训练时记录的解析版本。模型的完整标识和版本保留在来源区。方法库继续提供科学分类、适用条件、参数与来源。

## 设置

设置提供账户、外观、通知、消息通道、记忆、工具、技能和知识资料管理。关于页面提供 ChemAgent 的说明和项目入口。
