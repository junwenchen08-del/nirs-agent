# 工作台操作

## 数据集库

打开数据集可查看样本表、光谱和解析概要。修改角色或区间后保存，使用已保存版本挂载到会话。

## 建模过程

通过时间线或关系图选择轮次，查看实际配置、指标、预测与残差诊断，以及下一条已记录的提案。刷新后会恢复同一会话中的选择。

## 模型库与方法库

模型详情显示可验证的数据来源、训练信息和报告。方法库提供现有专业方法的说明与参考。

## 设置

设置提供账户、外观、通知、消息通道、记忆、工具、技能和知识资料管理。关于页面提供 ChemAgent 的说明和项目入口。
