# 数据与评价范围

## 数据集与解析版本

数据集保存输入文件；解析版本记录字段映射、样本角色和分析区间。开始建模前确认目标列、光谱方向和样本角色，保存后再挂载到会话。

## Cal、Cal CV、Val 与 Test

Cal 表示用于拟合的数据，Cal CV 表示 Cal 内的交叉验证，Val 为搜索阶段的验证数据。独立 Test 只在最终评价阶段使用。请按图表和指标标注的范围理解结果，不要混用这些分数。

## 决策与执行

模型提出的方案与实际执行参数分别记录。下一轮建议来自已保存的模型提案；没有提案时，页面不会生成建议。用户问题需要在会话中回复，浏览页面不会继续建模。
