# From data to model

1. Upload a dataset and confirm spectra, targets and sample roles.
2. Save the parsing profile, attach it to a chat and describe the property to predict.
3. Answer clarification questions and wait for the authorized analysis.
4. Inspect proposals, executed configurations, scoped metrics and diagnostics for each round.
5. Review the final report and verified input links; approve registration when appropriate.
6. Attach a saved model to a new chat and supply compatible unknown-sample data for prediction.

Missing historical points remain explicit. Interpret results using actual data quality, evaluation scope and report limitations.
