# Getting started

1. Sign in to ChemAgent. An administrator initializes the first account.
2. Upload a dataset and inspect target columns, spectral orientation, wavelength axes and sample roles. Correct ambiguous mappings in parsing settings.
3. Save the profile, attach the dataset to a new chat, describe the target and constraints, and submit manually.
4. Reply in the same chat if the agent asks for clarification. A waiting question does not resume automatically.
5. Inspect actual rounds, scoped metrics, diagnostics and reports in the modeling process. Model registration follows human approval.
