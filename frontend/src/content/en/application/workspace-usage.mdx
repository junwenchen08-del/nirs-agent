# Using the workspace

## Dataset library

Start a chat by uploading data, choosing a dataset or using a saved model. Selecting a resource never starts a run; manually send your task to execute it.

Dataset tabs contain samples and spectra, the overview, and parsing settings. Adjust intervals beside the spectra and assign roles in bulk after selecting samples. Save changes before reuse; leaving with unsaved edits requires confirmation.

## Modeling process

The full process canvas covers preparation, experiments, final evaluation, delivery and saving. Click a node to inspect Overview, Parameters, Diagnostics and LLM advice in equal-height panes. Timeline and recorded-relation views remain available; node and section selection restore after reload.

Chart groups contain prediction diagnostics, spectra, parameter searches and round comparisons. Scatter and residual plots share sample selection and zoom; process charts support enlargement. Final Test plots read completed evidence only. Missing historical charts are explicit and never recomputed on viewing.

## Models and methods

Model tabs contain prediction results, training data and processing steps. Switch between recorded evaluation scopes; linked previews use the recorded training profile. Exact model IDs and versions remain in source details. The method library retains scientific categories, applicability, parameters and references.

## Settings

Manage accounts, appearance, notifications, messaging channels, memory, tools, skills and knowledge sources. About provides ChemAgent help and project links.
