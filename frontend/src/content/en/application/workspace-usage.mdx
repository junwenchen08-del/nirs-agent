# Using the workspace

## Dataset library

Inspect sample tables, spectra and parsing summaries. Save role and interval changes before attaching a profile to a chat.

## Modeling process

Select a round in the timeline or relation graph to inspect executed configuration, metrics, prediction and residual diagnostics, and the next recorded proposal. Selection restores within the same session after a reload.

## Models and methods

Model details expose verified input links, training information and reports. The method library explains available analytical methods and references.

## Settings

Manage accounts, appearance, notifications, messaging channels, memory, tools, skills and knowledge sources. About provides ChemAgent help and project links.
