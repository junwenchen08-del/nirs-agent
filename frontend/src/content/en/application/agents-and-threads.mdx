# Chats and analysis records

Each chat retains its own messages and analysis records. Attaching a dataset or model does not start a run; submit the task manually. Answer clarification questions in the original chat.

Opening historical analyses reads recorded evidence. Page operations do not retrain, resume execution or change the retained model. Share links point to the current ChemAgent instance and still require the appropriate access.
