# Data and evaluation scopes

## Datasets and parsing profiles

A dataset stores an input file. A saved profile records field mappings, sample roles and analysis intervals. Confirm these before attaching a dataset to a chat.

## Cal, Cal CV, Val and Test

Cal is used for fitting, Cal CV is cross-validation within Cal, and Val is validation used during search. Independent Test is used at final evaluation. Interpret each score within its labeled scope.

## Decisions and execution

Proposed plans and executed parameters are recorded separately. Next-round recommendations come from saved model proposals; reading a page does not generate a recommendation or resume a question waiting for a user reply.
