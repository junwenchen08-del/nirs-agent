## 已实现

- 顶部紧凑任务摘要：Cal 样本、变量数、实验数、保留轮次、Test 状态与返回原对话。
- 阶段导航按数据准备、方案搜索、最终评价和交付审批分组，右侧详情扩大到约 72%。保留轮次时间线、真实关系图、历史分页与刷新定位。没有显式标签参数的数据节点刷新后恢复概览；明确选择的光谱标签继续恢复。
- 数据节点提供数据概览、数据结构和原始光谱；来源字段来自固定的搜索准备回执，展示文件名、格式、大小和短校验标识。单独的输入执行记录缺失时仍保持缺失。
- 原始光谱使用已有 Cal 缓存。每轮原始/处理后光谱共享缩放、样本显隐及重置，放大图保持联动。
- 轮次详情使用本轮变化、实际方案、结果与诊断、决策与建议。实际方案/参数与提案分开。
- 新增同会话实验对照，默认选择真实反馈来源。仅成功配置、比较组及 CV manifest 依据一致时显示范围匹配的指标差值；不会据此改变保留模型。
- 按用户去重要求，下一步优化建议仅在“决策与建议”标签内展示；本轮依据和预期也集中到这里。其他标签和底栏不重复建议入口。建议仍来自下一条已接受的原始提案，执行状态单独展示。
- 最终结果与交付集中已有最终指标/图表、验证局限、文件和审批状态。
- 等待用户时保留原问题和返回对话入口；页面操作不能解除等待。

## 保留的边界与后续工作

1. 历史来源、矩阵映射、质量检查或图表未记录时，不从文件名猜测，也不读取原始数据重建。
2. 当前过程接口没有独立的未来任务建议字段，最终页不放建议占位区；逐轮原始提案仍可在唯一的“决策与建议”标签查看。未来若增加该字段，需要绑定原始结论及执行状态，不能在 GET 时调用模型。
3. 新增 PCA、目标分布、离群诊断、变量贡献等采集，以及跨轮同样本残差差异图，属于后续证据扩展，不在本次实现范围内。
4. 不修改模型选择、数据划分、Test 租约、运行资源或人工审批。图表浏览不触发拟合、模型请求、最终评价或注册。
