# 模型注册后自动保存至模型库（2026-10-06）

此前 `nir_register_model` 只写会话内的 `registry.json`，模型库查询的是持久模型表。用户注册成功后若没有再要求 `nir_model_promote`，模型库就没有对应记录。

## 当前行为

- 模型库启用时，`nir_library.auto_save_registered_models` 默认开启。智能体经过用户审批并成功注册后，由工作流运行时自动保存同一个模型和版本。
- 返回值和工作流状态中的 `model_library` 分别记录 `saved/reused/failed/disabled/skipped`，不会把注册成功误报为持久保存成功。
- 继续通过 `ModelService` 核验所属用户、审批、科学验证、原注册版本、模型与指标哈希、训练数据绑定、签名策略及存储容量，复制验证后的原文件，保留原验证范围。
- 可以关闭自动保存或明确要求不保存。保存失败不撤销已经完成的科学注册；用户可明确要求重试保存。
- 已结束的审批注册工作流也可补保存。必须存在与当前已审批证据匹配的实际注册记录；未审批模型、任意上传模型或其他尝试的模型不满足保存条件。
- 查询列表本身仍是只读操作，不触发补保存。历史记录通过正式保存服务处理，不直接插入模型表。
