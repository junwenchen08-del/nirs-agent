# 上传数据集自动入库（2026-10-05）

启用数据集库后，网页成功上传的 CSV/TXT/MAT 默认自动入库，不再依赖智能体收到保存指令。
名称初始为上传文件名，可在光谱数据集库重命名。新对话输入 `/datasets`、选择数据集、
点击“挂载到会话”即可复用，智能体仍会重新审查原始数据。

## 行为边界

- `nir_library.enabled` 保持现有开关；`auto_save_uploads` 默认 true，设置 false 可关闭自动保存。
- 上传接口在完整批次验证及沙箱同步成功后保存，失败上传不会提前创建长期数据资产。
- 复用既有不可变源文件、SHA-256 校验、同一用户内容去重与容量限制机制；不同用户的数据隔离。
- 上传可发生在第一条消息运行前，因此创建明确归属的对话元数据；并发创建后重新校验归属，不接管旧的无归属对话。
- 每个文件的 `dataset_library` 返回 `saved`、`reused` 或 `failed`，包含数据集编号或稳定错误码。
  网页显示中文结果。入库失败不会删除已上传文件，也不阻止当前对话使用它。
- 已归档、校验失败或不可用的旧资产不会自动恢复。手动补存仍保留显式意图检查。
- 不自动确认解析 Profile，不继承旧模型结论，不改变模型审批、注册或长期模型保存流程。
- 本次不会批量回填历史上传；自动保存作用于更新后的上传请求。
