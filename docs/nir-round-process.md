# 自主建模轮次与诊断视图

页面保留左侧约 230px 的竖向阶段与轮次导航，右侧展示选中轮次。四个旧轮次页签已取消，改由“原始输入 → 有序预处理 → 模型 → 验证结果 → 决策与下一步”统一控制详情。打开已完成轮次默认展示验证结果；旧 nir_tab 链接映射到对应节点，明确 nir_step 时优先恢复该步骤。左侧四个阶段以连线与箭头组成竖向管线，“数据准备”和“逐轮建模”支持展开收起。数据准备展开文件进入、解析确认、分区准备，逐轮建模展开各轮与停止事件。子节点复用原记录与状态，点击后联动右侧；收起不改变右侧选中内容和 URL。数据准备不在右侧重复一组导航卡片；最终评价和交付仍使用各自入口。窄屏导航排在内容上方，宽度不溢出。

顶部一句本轮行动仅依据实际参考配置描述沿用、替换、调参及移除；缺少证据不推断变化。预处理节点只展示本步累计 Cal 光谱（绘图区高 210px）、参数与原始/上一步放大对照。选择样本、显隐和缩放在光谱步骤间保持；切换轮次不会混入旧数据。原始节点展示已有文件名与目标，缺失保持明确。模型节点集中实际参数、原执行的 Cal CV 参数评价和执行前搜索计划。完整计划与最终拟合配置不相互覆盖。

验证节点只显示一份 Val RMSE/R² 与合法参考变化，更多指标收起，Cal CV/Cal 通过范围切换查看。散点与残差共用选择和缩放。参考身份、成功配置、比较组、CV manifest 与指标范围均核对后才计算差值；手动对照不冒充智能体参考。Test 仅在最终评价阶段读取原缓存。

决策节点只显示持久化后续行动、记录理由、保留轮次、执行状态和跳转。停止／保留是决策事件，不增加模型拟合。当前轮次执行前判断和预期收于同一处补充说明，claim 等结构化观察转换为可读正文，内部引用和无法解释的对象不变成空编号卡片。备选方案、完整配置和技术编号统一保留在一个“运行记录”折叠区。展示不调用模型生成新建议。

## 节点和关系

建模过程页顶部保留“工作区 › 建模过程”面包屑；其中“工作区”直接返回当前过程所属的原对话，悬停提示“返回当前对话”。目标由页面的对话 ID 确定，直接打开、刷新或此前访问其他对话时也不会跳到新对话。该行为覆盖自主与历史过程及证据不可用状态；其他工作区页面的链接保持原有含义。导航不会启动建模或代替用户审批。浏览器回归：`process-chat-navigation.spec.ts`。

- 每条已接受决策对应一个节点；STOP、资源终止时的 RETAIN 与训练动作分别显示。
- 每轮通过“参考第 N 轮”表示实际记录的 `base_experiment_id`，不推断前后依赖或额外分支。STOP/RETAIN 作为独立决策事件，明确显示保留实验，不添加虚假的拟合管线。
- 最终保留、最低 Val RMSE、最后执行保持不同含义。最低分标记不选择或替换模型。
- 方案备选留在详情中，提出不等于执行。失败和待执行方案不展示成功指标。
- 行内箭头只表示本轮处理步骤的展示顺序。变化标记只对照记录的参考轮次，区分沿用、新增、替换、调参、顺序调整；未加载参考证据时标为待核对。移除或被替换的方法单独注明。成功实际配置优先于计划，失败或待执行方案明确标为计划。
- 数据节点使用“数据概览 / 数据结构 / 原始光谱”，分区节点使用“分区概览 / 验证协议 / 分区图”。轮次仅使用管线节点控制同一个详情区域，参数搜索归模型，指标对照归验证；趋势入口默认收起。
- 验证默认对照已记录的反馈来源，可按需选择同会话其他实验。变化计算保持原比较约束，不自动替换保留模型；顶部不重复指标或差值。
- 手动选中的历史轮次在更新时保持打开；URL 保存会话、决策/阶段节点、详情分区、当前阶段与步骤。历史按 20 条分页读取，自动读取前 100 条，其后可继续加载。
- 等待用户回复的提示只读取相同搜索会话的持久问题；页面操作不能恢复执行。非模型主动停止的结束状态独立展示。

## 每轮证据

`nir_core.model.safe_search.SearchFit` 在内存中保留原本用于指标计算的 Cal 拟合、Cal CV 折外、Val 预测，不增加拟合或重复预测。搜索执行器在原训练执行内将有界诊断证据写入会话私有目录的 `<experiment_id>.diagnostics.json`，结果记录 SHA-256。图表保存失败单独记录，不改变已完成模型、参数、指标或资源计数。

每个范围最多 2,000 个确定性等距样本点，带全量/显示数量、抽样说明和不透明样本 ID。Cal 和 Cal CV 共用 Cal 样本标识，Val 使用不同标识。同一会话不同轮次的样本标识稳定。散点图与残差图共享选择和实测值缩放；残差为预测减实测。全量指标不由显示点重新计算。候选参数表的 Cal CV 分数仍为各折 RMSE 均值，折外图对应完整 OOF 预测，两者不混称。

只读接口：

```text
GET /api/threads/{thread_id}/nir-process/autonomous/{session_id}/diagnostics/{experiment_id}
```

接口校验线程所有权、会话与成功实验归属、缓存尺寸/哈希、模型和决策身份、固定划分/CV 比较绑定，以及数值向量/样本 ID/残差一致性。它不加载数组或估计器，不训练，也不打开 Test。缺少历史缓存返回 `not_recorded`，写入失败返回 `failed`，文件丢失或损坏返回 `unavailable`，不为旧运行补算。

新 Cal 光谱缓存使用 v2：可信搜索执行器在原执行内，使用真实 Cal 拟合状态对最多 12 条固定 Cal 曲线进行一次有界变换；逐步观察累计输出，保存原始、每步和完整输出。中心化、MSC 等参数不在预览子集上重新拟合。各图保持相同样本标识及原始轴顺序，总通道预算随步骤数分配（单图最多 512 个通道），不改变实际训练分辨率。记录绑定会话、决策、实验、实际步骤与模型哈希，缓存受原有大小与 SHA 校验保护；图表失败不改变模型成功或拟合计数。GET 验证步骤顺序/参数、样本/轴一致性、有限数值及最后步骤等于完整输出，不打开数据数组或估计器。旧 v1 原始/完整输出缓存保持只读；确切配置一致时，完整输出可显示在最后一步，中间缺图明确标注，不补算。独立 Test 仍只在最终评价完成后读取原有缓存，不加入搜索节点的图表范围。

文件与数据解析节点展示准备时固定的来源回执及数据规模。`data_context.source_file` 仅包含验证过的文件名、扩展名、字节数与 SHA-256；界面默认展示短校验标识，不提供服务器路径。缺失回执不会根据文件名寻找当前版本或读取原始数据补齐。“来源已记录”不等于曾单独执行输入阶段。原始光谱预览复用已保存的 Cal 曲线；原始/处理后图共享区间和样本显隐，放大视图也保持联动。

契约位于 `contracts/nir-round-diagnostics-v1.schema.json`。没有修改 ProcessStore/应用数据库版本、模型选择规则、划分、Test 租约或审批规则。

## 验证

提案校验记录作为管线下方的次要折叠入口，确认没有拒绝事件时不显示；读取失败不能当作零事件。逐步光谱和前后对照只在上方预览中展示；下方“结果与诊断”仅保留“预测诊断”和“参数搜索”，移除重复的“光谱对照”入口及占位说明。旧记录缺失中间图不会补算；新运行记录实际执行过的每一步。

维护用例为 `backend/tests/test_nir_round_diagnostics.py`、`test_nir_autonomous_router.py`、`test_nir_safe_search_core.py`，前端为 `round-process.test.ts`、`round-pipeline.test.ts`、`round-pipeline-row.test.tsx`、`autonomous.test.ts` 和 `nir-round-process.spec.ts`。

设置 `NIR_ROUND_QA_FIXTURE` 为仓库外 JSON 路径运行 `test_real_round_browser_fixture_and_shared_contract`，可导出两轮真实算法计算、停止保留与一次独立 Test 的证据，再将同一环境变量传入浏览器用例。数据是测试专用合成数据，模型调用来源是 Fake 测试提供者；浏览器用例拦截 HTTP 并消费这些真实计算导出。此验证不等于真实模型提供者或在线生产环境验收。导出、日志和截图留在本地，不纳入提交。
