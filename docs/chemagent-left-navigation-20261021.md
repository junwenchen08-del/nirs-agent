# ChemAgent 左侧流程导航与紧凑图表整改（2026-10-21）

## 实现

- 左侧约 230px 竖向排列数据准备、逐轮建模、最终评价、交付审批。逐轮建模下列出各轮及真实执行状态、保留标记，历史分页和刷新仍在同一查询中。
- 右侧只呈现选中轮次，默认选择保留实验。切换轮次定位当前内容；点击步骤定位对应光谱或参数／诊断。刷新、会话 URL 和轮次证据身份保持原逻辑。
- 当前轮次顶部使用紧凑步骤条，保留沿用、替换、调参等基于实际参考实验的变化标记。
- 光谱图组按内容宽度显示 1／2／3 列。小图绘图区固定 210px，标题和坐标按实际容器布局，不缩放固定大画布；窄图减少刻度。放大和前后对照仍保留完整图表控件。
- 样本聚焦、显隐、缩放、重置和统一纵轴只在图组上方设置一次；原始和各步骤曲线持续联动。缺失的历史中间步骤保持显式提示，不使用最后输出冒充中间图。
- 预测与残差也使用紧凑预览，样本和缩放集中设置，放大时可查看完整诊断。
- 逐轮趋势默认收起在“轮次对比与优化趋势”。当前参数、验证指标与下一步建议继续使用既有记录，轮次详情不再重复大标题和大指标块。
- 不足 640px 时左侧导航移到内容上方并限制高度，避免内容被挤压或横向溢出；桌面端保持左右布局。
