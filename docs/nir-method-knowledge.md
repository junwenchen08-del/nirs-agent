# 算法知识引导的首轮预处理

本阶段覆盖电脑浏览器网页和单目标回归，包括 MAT 多子集逐子集分析。
模型族沿用现有选择机制；分类、多目标建模与校准迁移未改动。

## 已实现的数据流

上传 → 数据审查 → 固定划分 → Cal 光谱诊断 → 方法知识检索 → 首轮有界候选 →
Cal 内部交叉验证 → 固定预处理 → 原模型/变量选择 → 最终留出评估 → 图文报告。

规划阶段新增只读 `nir_search_method_knowledge(query, top_k)`；智能体可在审查后查询
方法名或“高频噪声”“基线漂移”“散射”等问题。正式训练不信任规划阶段对全部上传
数据的诊断作为选择依据，而是在划分后用 Cal 重新诊断和检索。

## 知识库与来源

`nir_core/knowledge/method_cards/chemotools-preprocessing-v1.json` 当前内置 94 张整理后的方法卡。
保留 21 种已接入预处理及 4 种回归参考，复用 16 个 Chemotools 类的已有卡片，
补充其余 69 项参考（包括辅助函数、常量和示例数据），覆盖官网导航 70 个文档条目
及当前 0.4.4 MCP 的全部 84 项公开能力。文件名保留安装兼容性，索引版本为
`nir-methods-v3-full-chemotools`。
`chemotools-inventory-v1.json` 记录官网导航清单、下载日期、页面 SHA-256、文档签名、
参数说明及版本固定的 MCP 目录事实，用于覆盖检查和绑定白名单。网站目录页本次
返回 503，实际条目清单取自可访问的官方预处理页完整方法侧栏，并逐页下载核对。
每张卡保存官网链接与章节、整理日期、用途摘要、问题标签、文档参数、参数映射、
项目搜索值、项目注意事项和审核状态。EMSC 仍为显式选择方法，检索不会自动执行。

预处理主要来源为 [Chemotools 方法文档](https://chemotools.org/methods/index.html) 下对应方法页。
回归模型引用 scikit-learn 官方文档；项目自有稳健 SNV 与去尖峰使用 SciPy 原语文档加
项目实现说明，明确不是对应算法的 Chemotools 实现。
官网为无固定版本的实时文档；2026-10-05 全量核对后整理为本地快照，运行时校验版本为 0.4.4。
方法卡 `content_sha256` 是整理后卡片内容哈希，不冒称官网页面原文哈希。
`evidence_id` 包含方法 ID 与内容哈希摘要；完整卡片保存在本次模型/指标选择证据中，
后续修改卡片不会改变已经产生的证据。

本阶段采用 SQLite FTS5 BM25 加中英文问题词展开与诊断标签过滤，为小规模方法库提供
可复现的结构化检索。每次加载内置或网页维护的版本化快照并构建内存索引，无联网抓取、嵌入模型下载或
外部服务依赖。此处不是新增向量语义索引；既有 Chroma/BGE 论文库保持独立。
排名分数不是可靠性概率，也不用于决定最终预处理。原始光谱不会进入索引。

## 选择与回退

MCP 全量参考的 `method_kind=mcp_reference`。它们可由规划工具检索，但不会进入
Cal 诊断驱动的普通预处理候选。网页按方法类型、15 个算法分类及名称/用途筛选，
覆盖计数与启用状态分别显示；停用卡仍算已收录文档，但不会进入检索。
`mcp_available` 和 `mcp_execution_supported` 来自当前安装包的只读 MCP 目录，
`mcp_parameters` 展示真实构造/函数参数 Schema、必需输入和操作名单。非有限默认值
以 `default_repr` 保存，不向网页输出非法 NaN JSON。
这些不是可编辑自动搜索组合，管理接口拒绝非空 MCP `candidate_params` 或修改
绑定/Schema。模型、数组、轴、参考量等复杂输入必须在实际 MCP 调用中提供，
执行前调用 live describe/validate，拟合仍受训练边界与工作流门禁约束。
Schema 主要描述类型、名称和必需输入，不能据此声称所有数值语义已校验。

网站与安装版本存在差异，PLS 官网新签名不应替换当前安装包的构造参数。
官网参数单独显示，并记录参数集合差异。官网校验函数
`chemotools.adaptation.validation.check_metadata_function` 未被当前 MCP 暴露，
保留为可检索、不可执行的文档参考；不替换为不同的 `check_array`。
`BasePlot` 是不可实例化抽象基类；数据加载接口、显示辅助函数、颜色/标记常量
明确标注用途，不冒称预测算法。`MetadataFunctionTransformer` 需要 callable，
JSON 卡片不能定义任意 Python 函数。迁移、监督变量筛选和数据增强也不自动
拼入普通预处理；分别需要配对仪器数据、折内模型或训练内增强的执行协议。

- 自动建模在首轮先运行有依据的候选，原始光谱为同批对照；不再要求独立先跑一次 raw+PLS。
- 小/标准/扩展预算保持最多 4/8/12 个候选、每个最多 2/3/3 步。参数变体轮流安排，
  防止某个方法占满预算，仍为原始谱和规则候选预留空间。
- 官网默认值、合法约束、官网明确建议范围与项目搜索值分别记录；没有证据就不宣称
  某方法仅适用于某种光谱，也不声称项目搜索范围是官网最优范围。
- 每个候选通过运行时注册表校验。仅稳定方法、匹配的提供者类与版本、允许自动选择的
  方法可进入候选。非等间距已知光谱轴不自动使用索引平滑/差分基线方法；没有轴时
  只能说明按变量索引处理，不能推断物理间隔。低信噪比不自动使用一阶导数。
- 状态拟合在每一 CV 折内部重做；使用校准内部 RMSECV 的 1% 简洁性规则确定最终流水线。
  调参集支持后续变量/模型选择，Test 从不参与方法检索、参数或候选采用。
- 无相关诊断标签、无匹配、版本不兼容、检索不可用或没有合法参数时，记录回退原因并
  使用现有规则候选。数值失败的候选保留为失败证据；非有限分数记录为空，不污染网页 JSON。
- 官方方法参考不计作独立研究，不能推进论文重试门禁、修改质量阈值或代表生产批准。

## 入口和兼容性

`nir_analyze(auto_preprocess=true)` 与多子集分析默认启用。
`nir_train_auto_split_model` 和 `nir_train_partitioned_model` 默认 `pipeline_steps="auto"`。
`nir_train_model(pipeline_steps="auto")` 对原始 NPZ 启用；其 `None` 仍表示已预处理输入。
用户指定 JSON 流水线保持原样；`[]` 明确选择原始光谱。

网页“查看完整建模过程”的预处理步骤增加诊断与算法来源卡片；报告增加诊断问题、
方法说明、项目使用边界及可点击官网链接。实际流水线和执行分数另行记录，不能将
检索命中解释为已经执行或最终采用。历史报告与过程没有新证据时不补写推断。

## 维护

日常维护使用“设置 → 知识库 → 方法知识库”。管理员可以编辑名称、用途、来源链接及章节、
检索关键词、适用/避免问题、项目注意事项、候选优先级和参数组合，保存草稿或保存并启用。
草稿和停用卡不会进入检索。“恢复内置版本”会恢复该方法的内置内容和状态，需在界面确认。
恢复不会清除修改记录；新增卡片没有内置默认时不显示恢复按钮。

网页修改保存到应用数据目录 `knowledge/methods.sqlite3`；Docker 既有 `.deer-flow` 挂载
负责持久化，容器重建和网页刷新不会丢失编辑。内置 JSON 不被覆盖。每次保存自动递增
修订号与 `index_version`，记录方法、操作、账号和 UTC 时间，界面展示最近 30 条。
参数或项目说明编辑保留原资料整理日期，修改时间另记在历史中，不冒称重新抓取了官网。
保存带期望修订号；别的窗口先保存时返回冲突，用户取消编辑并刷新后再修改。
正式训练在检索时读取最新已启用快照，现有模型和报告保留原证据。

网页新增方法卡只允许绑定已有稳定预处理、已列入目录的回归或 MCP 参考。算法代码、
提供者类/版本、运行时参数范围、光谱轴约束与自动候选资格不能通过管理界面放宽。
参数字段展示运行时默认、上下界与奇数要求；跨参数约束由服务端检查。
参数组合逐轮进入候选比较，仍受 4/8/12 的整体预算约束；低信噪比时的导数禁用
不会因修改卡片的避免标签而被移除。
检索测试仅预览已启用方法，不训练模型、不改变质量门槛，不需要论文 RAG 服务。

维护内置源码卡片时，重新核对来源、日期、文档参数与项目提供者映射，递增 `index_version`。
应用已存在网页快照时以网页维护的完整快照为准；单卡恢复会取当前镜像中的内置版本。
不要将未审核网页或上传文档直接发布为可执行方法卡。新增方法必须先进入运行时注册表，
通过算法验证后才可在方法知识中成为自动候选。算法卡已配置为 nir-core 的安装包数据。

## 内容扩展（2026-10-05）

当前覆盖如下。这里的“全部”指当前普通预处理注册表，不代表 Chemotools 全站算法。

| 类型 | 方法 |
| --- | --- |
| 散射与稳健标准化 | SNV、稳健 SNV、RNV、MSC、EMSC |
| 平滑与尖峰 | SG 平滑、Whittaker、中值滤波、孤立尖峰去除 |
| 导数 | SG 一阶/二阶、Norris-Williams 一阶/二阶 |
| 基线 | AsLS、AirPLS、ArPLS、多项式去趋势、Rubberband |
| 缩放 | 均值中心化、自动缩放、向量范数归一化 |
| 回归建模参考 | PLS、Ridge、SVR、Extra Trees |

所有卡片增加 `applicability_zh`、`limitations_zh`、`parameter_guidance_zh`，
网页可展开查看及编辑，并按预处理/回归建模筛选。来源参数、项目接口约束、实际项目
搜索网格分别说明；适用建议标记为项目解释，不声称官网给出了某光谱类型的最优参数。

提供者对照；官网文档没有固定版本保证，实时名称可能与已安装版本不同。
