# ChemAgent 界面改版实施记录

日期：2026-10-17。设计基线：`chemagent-ui-design-plan.md` v1.4；代码基线：`3f9a2e4b55c268a756d45d4c13e770b6748e33b5`。当前为本地开发，未提交、推送或重建生产 Docker。

## 实现范围

- 基础：中性背景、统一青绿色强调、中文系统字体、可见键盘焦点、深浅主题和减少动态效果。侧栏采用 240px / 64px，窄窗口首次默认折叠，保留显式选择；最近对话显示八条，完整历史仍在原对话列表分页。
- 新对话：上传数据、选择数据集、使用已有模型三个业务入口复用原文件选择和资源挂载流程。没有隐藏提示词或自动执行。
- 数据集库：去掉四张大统计卡，以一行摘要显示数量与体积。卡片突出样本、变量和真实目标，次级操作收进菜单。异常、读取失败、待确认和空态继续区分。
- 数据工作台：样本与光谱、概览、解析设置三个主分区。波段控件靠近图表，选中后显示批量用途控件；草稿、跨页选择、原值只读、保存版本和离开保护沿用原链。详情面板与库内入口共用解析、版本和使用历史组件。
- 模型库：显示名称只取已记录目标与算法，缺失则保留原 ID。卡片只显示一个范围的指标；详情按预测效果、训练数据、处理方法组织，评价范围可切换。精确版本与已验证的冻结数据预览继续保留。
- 建模过程：原有决策查询、分页、选择恢复和关系图继续使用。新增从输入、解析摘要、分区准备、全部已接受决策，到冻结、最终 Test、交付、授权、入库的纵向画布。展示顺序线与真实反馈/保留关系明确分开；未发生或未记录的节点使用明确状态。
- 节点详情：左右等高，标题、方法、关键指标与页签固定，正文在面板内滚动。概览、参数、诊断图、LLM 建议均直接可达；参数保留固定、搜索与最终拟合三种含义。原始下一轮提案、原因、预期与后续执行状态仍来自同一轮的精确记录。
- 图表：散点与残差按容器宽度并排或上下显示，样本选择与缩放联动。光谱、候选搜索和轮次比较按图组组织。过程图可放大，键盘可选择样本，放大使用独立 SVG 标识避免剪裁冲突。最终 Test 双图也共享选择；完整最终拟合指标保留可展开入口。
- 聊天侧栏改为 480px 建模进展摘要，并链接完整过程。首页改为静态、简短的三步工作台介绍；方法库及中英文使用文档同步。

## 原有要求与新入口台账

下表以当前源码、改版前 618 项前端基线、相关后端隔离回归以及本次浏览器交互为依据。浏览器测试使用受控 API 回放和真实算法生成的合成数据证据，不等于在线模型提供商或生产部署验收。

| 范围 | 当前入口与验收依据 | 保留方式 |
| --- | --- | --- |
| 品牌与中文 | 首页、工作台、docs；branding/chinese 单元与浏览器用例 | 中文首次访问、显式英文选择、兼容标识继续使用原实现 |
| 数据集上传、搜索与分类 | 数据集库；dataset-library / dataset-command | 原 multipart 上传与有界预览，失败保留文件和草稿 |
| 可视化解析与版本 | 工作台解析页签、库内更多菜单；dataset-parsing | 同一 DatasetDetailsPanel 复用原映射、预览、确认、版本及高级 JSON |
| 原值、角色、分页和波段 | 工作台样本与光谱；dataset-workspace | 原 API、草稿保存与哈希/Profile 校验；离开前确认 |
| 分区边界 | 原摄取/搜索服务；后端 web_csv_ingestion | 全未分配自动划分、显式成员固定等底层代码未改 |
| 精确模型与数据来源 | 模型详情训练数据/来源区；model-library、model-report | 原 report 契约和 pinned Profile 读取，错误身份不渲染 |
| Dataset/Model 挂载 | 三个新对话入口和资源页；dataset/model-command | 沿用取消、重试、附件保留与手动发送路径 |
| 等待、停止、保存 | 原 Lead/审批服务；后端 user_wait/runtime_stop/library_persistence | 没有改写状态或真实会话，浏览器只读检查等待问题 |
| 方法、参数与 LLM 建议 | 节点四个主分区；round-detail / nir-round-process | 精确 decision/session 绑定，陈旧响应不能注入建议 |
| 全部轮次、关系与恢复 | 全过程画布/时间线/关系图；round-process | 接受决策不删减；超过自动预取上限仍能手动加载 |
| 诊断、光谱与缺失状态 | 节点诊断图；round diagnostics / cal spectra | 原执行缓存；无浏览补算，失败/未记录/校验失败区分 |
| 最终结果与下载 | 最终 Test、交付节点及原下载页签 | 完成后按需读取原缓存与受保护 Artifact URL |
| 审批与入库 | 授权/入库节点只读，实际操作返回对话 | 只显示真实会话记录，不从 finalized 或交付推断批准 |
| 方法科学分类与管理 | 原方法库与设置；method-library | 浏览、参考、执行与管理权限保持区分 |
| 历史兼容 | 原路由、查询清理、legacy 过程视图 | 不新增 API client、工作流状态库或存储迁移 |

最终验证：

- TypeScript、生产 webpack 构建通过，29 个静态页面生成成功。全量 ESLint 0 错误；`messages/message-list-item.tsx` 中两条原有 Hook 依赖警告未改。修改文件的 Prettier 与 `git diff --check` 通过。
- 生产构建的主浏览器回归 66 项通过，2 项需要独立认证环境的用例按已有条件跳过。随后对新增的草稿保留和深色检查，以及受影响的工作台/解析/流程场景复验 19 项；去重覆盖 68 个通过的浏览器场景。
- 验证覆盖资源挂载不自动发送、上传失败重试、CSV/MAT 解析、角色/区间保存、跨页选择、草稿离开保护、冻结预览、范围切换、全部轮次、关系图、陈旧响应隔离、建议与执行分离、等待问题、最终 Test 按需读取、节点/页签恢复、图表放大、键盘样本联动、浅深主题和 320/390/720/768/1024px 紧凑窗口。

截图和测试输出仅在本地 `.tmp/ui-redesign/` 与被忽略的浏览器 QA 输出目录保存，不进入产品提交。截图包含测试专用合成数据；本次没有在线模型提供商验收，也没有生产 Docker 发布。

## 明确边界

- 历史未单独保存的文件进入、解析操作/时间、诊断点或建议不能补造。解析节点标明其信息来自准备时固定的数据摘要；具体实验方法/参数/结果均在各自节点。
- 审批和注册只读取同一会话记录；缺失记录不能显示成功。未来阶段的标题表示可定位阶段，不能证明已经执行。
- 没有新增分类训练协议、自定义模型持久名称、跨模型排行榜或持久化视图偏好。现有分类与历史流程保持兼容。
- 所有生产服务、配置、数据挂载、历史会话、模型包、审批和数据库均未在本次开发中修改。后续上线仍需要独立的新源码快照、部署审计与回滚记录。
