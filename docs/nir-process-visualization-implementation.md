# 建模过程可视化实现与验证

本次实施对应修订方案的单目标定量主链路。分类、多目标、校准迁移等专用图属于 P3。

## 已实现

- Sheet 速览保留，新增完整过程页面；步骤导航、运行与尝试切换、候选分页、深链接和刷新恢复。
- 执行开始前分配尝试编号，重复调用去重，并发编号唯一；执行状态和图表证据状态分开。
- 原始与处理后光谱使用相同代表样本标识；曲线开关、悬停、联动区间缩放、重置与数据表。
- 数据/分组直方图来自全量样本；波长保留区间精确记录，不把显示抽样当作筛选结果。
- 模型候选保留实际参数和分数；预测与残差使用相同不透明样本标识，可选点、框选和键盘操作。
- 图表与全量指标分开；明确校准、调参、留出/外部验证和最终重拟合范围。
- 严格同口径调参趋势、当前页最低分、有序事实差异；旧摘要和不完整口径不参与排名。
- 版本轮询、ETag、请求取消、按身份隔离的缓存；取消和异常落库，重启只恢复确认孤立的运行。
- 所有接口执行会话归属校验，图表校验归属/版本/哈希/尺寸；损坏文件显示不可用。

## 存储与生命周期

过程数据存放在 `users/{owner}/threads/{thread}/nir-process/`，位于沙箱可见目录之外。
独立 SQLite 索引保存运行、尝试、步骤、图表引用、去重事件和实际 Agent Run 关联。
采用事务性 `user_version=2` 自迁移，支持 1→2；未增加中心 ORM 表，因此无需中心 Alembic 迁移。
图表按 SHA-256 命名，临时写入/fsync/替换后才提交引用，单图上限 1 MiB。
线程删除一并移除索引和图表。读接口不接受用户文件路径。

API 使用 `offset` 分页：运行/候选每页 50、尝试每页 20。尝试深链接可定位所在页。
当前访问模式仅限会话拥有者；能力标识对应这一范围，不宣称支持受限共享查看。
开关默认开启，关闭方式见 README。关闭不删除原始模型与历史证据。

## 验证方式

后端测试验证真实 `nir_train_model`、`nir_analyze`、`nir_train_auto_split_model`、
`nir_train_partitioned_model`，对同一实际数据执行两次分析，检查指标、残差、样本标识、
比较组及旧图不可变。契约校验覆盖生产者输出。额外覆盖权限、版本、文件损坏、
并发编号、200 候选分页、取消/异常、重启恢复，以及旧会话不造数据。

前端单元测试覆盖参数顺序、严格比较、共享契约样例及显示点统计；浏览器测试消费
实际训练存储的导出，验证缩放、联动选点、候选详情、尝试切换、慢响应、刷新与紧凑桌面窗口。

```text
python -m pytest tests/test_nir_process.py tests/test_nir_process_router.py tests/test_nir_process_training.py tests/test_nir_workflow_middleware.py tests/test_gateway_run_recovery.py -q
python scripts/export_process_fixture.py STORE OUTPUT.json
NIR_PROCESS_QA_FIXTURE=OUTPUT.json pnpm exec playwright test tests/e2e/nir-process-explorer.spec.ts
python scripts/benchmark_process_evidence.py OUTPUT_DIRECTORY
```

尺度基准使用明确标记的独立合成数据，覆盖 1,000×1,000、10,000×2,000、20 次尝试、
200 候选，30 次读取。浏览器性能和后端读取性能分别报告，不将拦截 HTTP 的浏览器测试
冒充真实网络端到端延迟。结果及环境限制见
[本次验证记录](nir-process-visualization-validation-2026-10-04.md)。

## 中文展示优化（2026-10-05）

- 候选标识是按有序预处理方法及参数计算的 SHA-256 前 16 位；无处理步骤的标识为 `raw`。编号不表示排名，也不包含数据集或评估划分，不能单独证明结果可比较。
- 按同一步骤中已记录的标识关联推荐配置，展示真实预处理名称和参数。缺少或冲突的配置不猜测；相同标识的评估行保留独立点击状态。
- 指标、状态、评估范围、工具来源及方法参数使用中文名称；普通小数最多显示四位，小于 0.0001 的非零数保留四位有效数字。展示格式不修改原始指标。
- 内部编号、未知字段及原始完整记录默认折叠；“查看中”与“建模采用”独立显示。决策栏先解释已记录的选择规则，完整比较记录可展开。
- 全部 515 项前端单元测试通过；TypeScript、相关 ESLint 检查及生产构建通过。桌面 Chromium 过程页测试 6 项通过，1 项可选性能测试未启用；包含 1100 像素桌面窗口及中文候选详情验证。
- 浏览器验证消费既有实际训练导出并拦截过程 API，验证的是页面展示与交互。截图保存于本地 QA 目录；本次仅更新网页服务，不变更模型训练和评估逻辑。
