# 建模交付物改进

本次针对电脑浏览器网页，覆盖 `nir_analyze`、`nir_train_model`、自动划分、具名分区和 MAT 多子集分析。

## 使用方式

新建模默认展示完整 HTML 报告与 `delivery.zip`。HTML 自包含实际诊断图，下载后可离线查看，浏览器打印可保存为 PDF。
ZIP 内有报告、模型与原安全清单、完整指标、图表及 `delivery_manifest.json` 文件大小/SHA-256 清单。
模型路径和指标路径保持原有绑定；原始上传数据不打包。不新增审批、注册或模型入库行为。

报告包含结论摘要、数据与分区、实际选择依据、分区指标、诊断图解读、使用边界、复现与交付说明。
校准、调参和最终留出/外部验证分别标注；没有记录的单位或指标保持缺失。质量达标不表示生产批准。
波长单位不能由数值猜测。图解说明如何阅读，不编造异常诊断、化学归属或因果结论。

多子集总报告汇总每个成功子集的完整图文结果，记录失败子集，并打包所有成功子集的受信模型及指标。
`primary_subset` 保留原运行时证据引用规则，不声称跨子集最优。各子集分区不同，最终留出分数不用于自动注册选择。

已有网页附件识别到 NIR 交付集时，模型、指标和辅助图默认折叠，展开后仍可单独下载。
历史报告和模型不会自动删除、重写或重新训练。分类、多目标、预测和校准迁移专用报告格式不在本次改写范围内。

## 实现边界

- `_report.py` 从实际指标与工作流目标/单位生成有界 Markdown，不含 Base64。
- `delivery.py` 仅打包本次显式指定的文件，不递归扫描目录。拒绝符号链接与不安全 ZIP 路径。
- HTML 只渲染报告使用的有限 Markdown 语法，原始 HTML 转义；只有显式指定的本地 PNG 被嵌入，不请求远程图。
- HTML/ZIP 使用临时文件与原子替换；ZIP 清单哈希对应实际归档字节。
- Agent 全局输出指引和本地 `nir-coordinator` 输出规范优先使用 `deliverables`；用户要求时再单独展示辅助文件。
- 前端普通文件不折叠；报告相对图片走现有会话归属校验的工件路由。
