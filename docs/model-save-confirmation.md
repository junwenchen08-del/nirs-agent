# 模型库保存确认

结果页面在审批待确认时提示回复“同意保存到模型库”。后端将这句话以及明确的“确认保存到模型库”等中文肯定语句识别为登记授权，随后沿用原有的精确产物登记和自动入库路径。之前的识别规则仅包含采用、使用、注册等词，导致用户照提示回复仍被拒绝。

审批只读取最新一条真实用户消息的原文。系统提醒、技能激活、持久上下文和摘要不提供授权；最新消息否定保存、询问含义或只询问结果时，不回溯复用旧授权。保存不是训练入口，不重新选择模型，不读取或重新评估 Test。

登记和入库分别记录状态，只有模型库服务实际确认保存成功才展示入库成功。若模型生成的确认问题包含未经核实的指标或内部状态信息，待审批阶段显示可操作的“同意保存到模型库 / 暂不保存”提示，而不是丢失具体操作的笼统问题。

回归覆盖结果文案与真实审批工具的契约、文本块/上传元数据包装、最新用户消息及否定语句、实际登记后可列出的模型库记录，以及澄清提示的证据校验。历史会话和既有审批记录不由修复脚本改写。已停在旧澄清问题的会话需收到新的真实回复才能继续原来的已完成模型保存流程。
