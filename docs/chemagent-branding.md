# ChemAgent 产品品牌

所有面向用户的产品界面使用 ChemAgent：主页、登录、首次初始化、密码设置、聊天侧栏、欢迎语、通知、记忆导出文件名、设置菜单和关于页面。

`frontend/src/core/branding.ts` 定义产品名称和已验证的项目链接。帮助指向实例内的 `/zh/docs` 或 `/en/docs`；项目与问题反馈指向当前仓库。分享会话使用当前实例的 origin，访问权限仍由服务端校验。没有虚构的官网或支持邮箱。

图标由原生 SVG 绘制的分子轮廓和光谱线构成，页签使用 `/favicon.svg`。登录与初始化页使用光谱背景。旧吉祥物、旧 favicon、旧宣传图片、旧框架文档与演示产物已从产品静态资源删除；静态模式保留一份不含虚构分析结果的 ChemAgent 使用介绍。

中英文文档和产品文章只介绍 ChemAgent 的现有工作流。默认智能体自称 ChemAgent，API 文档和消息通道连接提示使用同一名称。自定义智能体名称继续由其配置决定。

默认语言为简体中文，首次访问不跟随浏览器自动切换成英文。已有明确保存的语言偏好继续恢复，外观设置中中文排在首位。初始化、密码校验、登录错误、登录回调、首页说明、文章目录与日期、文档反馈入口和主题选项采用中文友好的文案。文档主题未提供本地化接口的可选 AI 分享菜单不展示。

兼容性包名、内部协议头、持久化存储键、环境变量、历史会话和模型数据维持原有契约。第三方许可与版权声明保留在法律文件中。这次品牌更新不执行迁移、训练、模型选择或部署。

回归覆盖双语文案及关于页、公开文档与静态资源扫描、工作台导航、通知、当前实例分享、文档本地化跳转、默认智能体名称及消息通道回复。浏览器验收使用隔离的本地前端和测试认证服务，不读取生产数据。
