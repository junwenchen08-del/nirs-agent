# 数据集挂载与手动发送（2026-10-06）

聊天中的 `/datasets` 选择器曾将“挂载到会话”转换为挂载并检查数据集的用户消息，导致点击按钮立即启动智能体。现在按钮只准备当前会话的数据文件。

## 使用方式

1. 输入 `/datasets`，选择数据集并点击“挂载到会话”。
2. 输入框显示数据集名称和“已挂载，输入要求后点击发送”。
3. 输入分析要求并发送，智能体才开始审查和处理数据。
4. 数据集标签上的取消按钮只取消下一次发送的选择，不删除库中资产或会话副本。

## 实现边界

- 通过已认证、带 CSRF 防护的接口准备所属会话，再调用现有数据集挂载接口，不创建智能体运行。
- 挂载状态绑定当前会话。切换会话、关闭选择器或卸载输入框会取消进行中的挂载请求，旧响应不能添加新的选择。
- 手动发送通过 `additional_kwargs.files` 携带服务端返回的上传路径，不重新上传库中的文件；新上传附件仍走原有上传流程。
- 检查会话标识、路径、扩展名和大小后才接受挂载结果。服务端继续负责所属用户、资产和文件的最终校验。
- 发送失败时保留数据集选择；未确认成功的挂载不会触发发送。

## 验证

- 前端单元测试：62 个文件、524 项通过，包括会话准备失败、会话不匹配和挂载路径校验。
- 浏览器测试：7 项通过，覆盖挂载不发送、手动发送的原文和文件元数据、无需重新上传、取消选择、挂载失败、关闭进行中的挂载，以及上传自动入库的三种反馈。
- 修改文件的 ESLint、Prettier 检查、TypeScript 检查及 `git diff --check` 通过。
- 独立 Docker 网页镜像生产构建通过。浏览器测试使用模拟接口和合成记录，未修改真实数据集库。

本次改动仅涉及网页交互和前端发送元数据，服务端数据集库 API 保持现有契约。
